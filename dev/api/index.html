API reference

OMRuntimeExternalC — Module

Julia bindings to the external C functions of the Modelica Standard Library (tables, strings, I/O, files, random numbers, FFT) and the tool side of ModelicaUtilities.h. They call libModelicaExternalC, built from the C sources of the Standard Library (see libraryPath).

Loading the library

OMRuntimeExternalC.libModelicaExternalC — Constant
libModelicaExternalC::String

The name ccall uses for the library, as the JLL packages do: the library is loaded by its full path in __init__, and the system finds the loaded one under this name (its install name on macOS, its SONAME on Linux, its module name on Windows).

OMRuntimeExternalC.libraryDirectory — Function
libraryDirectory(environment = ENV)::Union{Nothing, String}

The directory with libModelicaExternalC, in the order of the list at the top of this file: the directory of the environment variable OMRUNTIMEEXTERNALC_LIBRARY_DIR, the build directory deps/usr/lib (bin on Windows), the artifact. nothing when none of them has the library file.

OMRuntimeExternalC.libraryPath — Method
libraryPath()::Union{Nothing, String}

The full path of the loaded libModelicaExternalC, nothing if the library was not found or did not load. Its functions are the Modelica external C functions of the Standard Library (dlsym finds them in it) and the safe_* functions of the shim.

source
OMRuntimeExternalC.loadLibrary — Method
loadLibrary()::Union{Nothing, String}

Load libModelicaExternalC with RTLD_GLOBAL, so that compiled external C code of a model, which calls ModelicaError and the other functions of ModelicaUtilities.h, finds them in the process. Returns the path, nothing (with a warning) if there is no library or it does not load.

OMRuntimeExternalC.ModelicaFFT_kiss_fftr — Method
ModelicaFFT_kiss_fftr(u, nu, work, nwork, amplitudes, phases) -> info

Modelica.Math.FastFourierTransform's real FFT (MSL's ModelicaFFT.c): the amplitudes |Xk| / nf and phases arg(Xk) of the frequencies k = 0..nu/2 of the real signal u, X_k = sum(u[n+1] * exp(-2impik*n/nu) for n in 0:nu-1), nf = nu/2 + 1. A direct sum over a table of the nu roots of unity (no FFT library; nu is at most a few thousand in the MSL examples); work is only checked for its size. info: 0 o.k., 1 nu not even, 2 work too small.

OMRuntimeExternalC.installErrorHandler — Method
installErrorHandler()::Nothing

Set ModelicaError(::Cstring) as the error handler of the loaded libModelicaExternalC (modelica_set_error_handler of the shim): an error that C code reports with ModelicaError or ModelicaFormatError while no safe_* function is running is thrown as a Julia error from the ccall that was running, instead of ending the process. The C frames between are left without cleanup, as the C code expects of ModelicaError (it does not return).

Called when the package loads. An error raised on a thread that Julia did not start has no Julia caller to catch it.
